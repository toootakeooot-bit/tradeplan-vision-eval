# Reports

## daily/YYYY-MM-DD/

- `morning.md`: 朝の進行中Direction / Entry Episodeの状態
- `evening.md`: 夕方の進行中Direction / Entry Episodeの状態

日次報告は件数や単純勝率ではなく、現在のシナリオ状態を短く示す。

## weekly/

週次は以下を総括する。

- 方向認識が機能したか
- Entry待機が適切だったか
- Entry後にTP/SLのどちらへ先に進んだか
- Entryが早すぎる/遅すぎる傾向
- 銘柄・相場環境に共通する癖
- 改善候補。ただし検証途中で元判定履歴は書き換えない
